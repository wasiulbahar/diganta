# Diganta (দিগন্ত · horizon)

A geography game played on real satellite imagery. One HTML file, no build step.

- **Guess the place**: 5 mystery satellite views, click where they are. Hints cost points; each round ends with a fact card and the clue that gave it away.
- **Journey**: travel from A to B by dragging the map, zoom locked.
- **Free ride**: explore anywhere, search places, toggle labels.

Run locally: `python -m http.server 8797`, then open http://localhost:8797.
